# P3.1 Selección de cor en rede
Crea un xogo multixogador no que os xogadores se sitúen aleatoriamente no plano e teñan un botón que pode facer que muden de cor aleatoriamente (entre 6 cores predefinidas). Podes partir do código do "getting started", pero limpa o código e organízao o mellor posible. (versión 1.0)

Limitar o número de posibles xogadores a 6. (versión 2.0)

Asegúrate que ao asignar unha cor calquera (tanto cando un xogador entra ao xogo como cando se lle da ao botón de cambiar cor) ésta non está sendo usanda por outro xogador (versión 3.0).

O script ou scripts relevantes na tarefa
O enderezo de github que contén o proxecto cos tags que se indican no enunciado
